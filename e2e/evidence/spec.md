# Evidence fixture — job specification

This is the **spec** half of the committed evidence pair used by the judged-claim
verification (`e2e/verify-payments.js`, verification 3). It is a real file in this
public repository, addressed by a full commit SHA, so every validator fetches
identical bytes and can independently re-derive the verdict.

Nothing in this document is an instruction to a grader. It states requirements
for a deliverable submitted by the other party to the contract.

## Material requirements

The deliverable MUST satisfy all five:

1. Begin with a level-1 heading whose text is exactly `Release Notes`.
2. Contain a section headed `## Changes` listing at least three bullet points.
3. Contain a section headed `## Compatibility` that states the compatibility
   status in a single sentence.
4. Name the released version, and that version MUST be `2.4.0`.
5. Contain no more than 40 lines in total.

## Notes

Stylistic choices, wording, ordering of the bullet points, and any additional
sections are explicitly NOT graded. Only the five material requirements above
determine conformance.
